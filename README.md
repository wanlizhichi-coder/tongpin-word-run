# 同频 · 双人词语跑

一个不用注册、打开链接就能玩的双人联机词语游戏首版。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的地址。房主点击“创建一局”，把生成的邀请链接发给朋友；朋友在另一台手机上打开链接即可加入。联机信令使用 PeerJS Cloud，双方只需要能访问网络。

## 玩法

1. 房主输入称呼并创建房间。
2. 朋友打开邀请链接，输入称呼加入。
3. 两个人分别输入一个词，提交前互相看不到。
4. 双方都提交后，答案同时揭晓。
5. 点击“下一轮”，继续输入，直到想到同一个词。

## 当前版本边界

这是快速可玩的 Web 第一版：房间状态存在房主浏览器内，房主关闭页面或网络中断后房间会失效；正式上线时可以把 PeerJS 房间状态替换为服务端 WebSocket/数据库，并补充断线重连和防作弊策略。
